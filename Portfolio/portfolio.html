Venture Phoenix: Planet Generator System

Unity C# Perlin Noise Random World Gen Mesh and UV manipulation

Venture Phoenix is a large project I have planned and a planet generator is a system component I will require for it.

Using Blender I made a Goldberg Polyhedron and used the mesh data to assign mesh triangles to the tile they draw. Tiles are then randomly assigned elevation, temperature and humidity which is used to assign one of 12 different biomes.

Blitztorm

Godot GDScript Wave survival Software development Game design/development State machine

Blitztorm is a wave defence project made in Godot inspired by an old 2D flash game Mud and Blood 2.

Player spends funds on units and cover, with upgrades, equipment and support to come. The goal is to survive as long as possible against ever growing enemy waves. RTS controls to move units along lines or in columns, Navmeshs for pathing, state machines to handle behavior logic, health and stats system

System Flow

Godot GDScript Professional Department of National Defence System design/development Simulation Fluid flow Training tool

System Flow is a fluid system simulator training tool I created under a casual contract with the Canadian Department of National Defence.

Systems are design using a graph structure. Tanks are resoviors of fluid, Pipes are responsible for transferring fluid around the system, pumps introduce forces into the system and all other components (valves, reduction stations etc) serve to control flow within the system. Systems are created as essentially interactive 2D engineer diagrams assembled to perfectly represent real systems on Naval warships.

Powerless

Unity C# 3D Horror Team lead Group project School Developer

Powerless is a 3D horror game where you must collect gear to restore the power while managing your flashlight's battery because light is the only thing that freezes the enemies... as supplies last

Find keys to unlock doors and path through the world to find components to complete the level. Batteries each have their own power quantities, so reloading and tracking the battery power as the player manages it becomes important. The flashlight causes enemies to freeze, and when that battery level is low the light begins to strobe. Jumpscare instadeath is what awaits the player who missmanages their batteries or loses track of an enemy.

I was responsible for the vast majority (>90%) of the development work for the game as well as acting as the group leader. Other members sourced/created models, assembled levels, created the jumpscare cutscene, but I was responsible for all the logic and tying their compnents together.

Anger Clanker

Unity C# 3D Platformer Puzzle game Realistic Physics School

Anger Clanker is a 3D realistic physics puzzle/platformer game where you must knock small robots off the map while cleverly removing/avoiding larger enemies while avoiding the void yourself

Player momentum cannot be changed while in the air leading to a challenging gameplay experience. Small enemies can be kicked off the map, as well as environmental objets like boxes. Large enemies patrol until the player is close enough in which they will try to attack them. The player cannot directly influence the large enemies but can use environmental objects to knock them off the map as well. The objective is to remove all small robot then exfill back to the starting platform. Boxes can be kicked and used to reach previously unreachable areas.

This was a solo school project, assets were provided but all code and level design and game features were thought of and created by myself
